# @desvio/design-tokens

Tokens do design system [Desvio](https://claude.ai/artifact/4axmnGJWvKEXczHh3RP4uq), versão 3.

- `tokens.json` — fonte única (formato do design system: cada família é uma lista de `{name, value, usage}`; cores com valor por tema `light`/`dark`)
- `tokens.css` — variáveis CSS geradas a partir do JSON

Ao mudar o design system, copie o `tokens.json` novo para cá e rode `npm run tokens` em `apps/mobile`.
